# French Ninja Creami Deluxe — site statique

Site statique gratuit compatible GitHub Pages.

## Contenu
- 76 recettes
- photos conservées
- recherche par nom, ingrédient, tags
- filtre kcal max
- filtre protéines min
- tri par kcal/protéines/A-Z
- fiches détaillées avec base, instructions, mix-ins
- favoris et notes perso en localStorage

## Important
Les données proviennent du texte fourni par Jeff dans la conversation.
Quand la macro d'origine indiquait `xxx` ou `xx`, l'app garde la recette mais signale que les macros sont à compléter.  
Pour certaines cartes, l'ancien index kcal est conservé avec un astérisque afin de ne pas perdre le tri visuel.

## Publication GitHub Pages
1. Créer un dépôt GitHub.
2. Envoyer tous les fichiers du dossier.
3. Settings → Pages → Deploy from branch.
4. Branch: main, Folder: /root.
